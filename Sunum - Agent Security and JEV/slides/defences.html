3 · DEFENCES

There are two kinds of defences.

The first kind

Asks the model, or another classifier, to notice the attack.

It fails when the attacker knows how it works.

The second kind

Uses fixed rules written in code and outside the model.

It works better, but the agent finishes fewer tasks.

Most papers show the same thing.

Birinci tür olasılıksal: modelden ya da bir sınıflandırıcıdan saldırıyı fark etmesini bekliyor. İkinci tür deterministik: kural kodla, modelin dışında uygulanıyor. Birincisi saldırgan onu bildiğinde kırılıyor; ikincisi dayanıyor ama ajan daha az görev bitiriyor. Sonraki slayt sayılarla gösteriyor.
