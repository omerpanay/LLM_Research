1 · THE PROBLEM AND THE ATTACKS

How does an attack get into the car?

The attacker never talks to the agent. They only change something the agent will read later.

1 · Hide

The attacker hides an order in a restaurant review, an email or a calendar invite.

2 · Read

The driver asks for something normal. The agent looks it up and reads the hidden order.

3 · Mix up

It can’t tell the order apart from the data, so it treats it like a real request.

4 · Act

It sends an email, changes the route or shares where the car is.

So the real question is not “Can someone talk to the car?” but “What does the car read?”
