How the main benchmarks decide

BenchmarkSizeWho decides success
InjecAgent (ACL Findings 2024)1,054 test casesCode: did the agent call the attacker’s tool?
AgentDojo (NeurIPS 2024)97 tasks, 629 security testsCode that checks the system state
AgentHarm (ICLR 2025)110 harmful tasks (440 with variants)Written rules; an LLM only for small parts
AgentLAB (ICML 2026)644 test casesAn LLM judge (GPT-5.1)
CAR-bench (ACL 2026)240 car tasks, 19 rulesCode for 12 rules, an LLM judge for 7

AgentDojo avoids LLM judges for a simple reason: an attack strong enough to fool the agent might fool the judge too. And That is really important point for evaulation process.

Bu tablo hangi benchmark'ın başarıya nasıl karar verdiğini gösteriyor. Eski benchmark'lar (InjecAgent, AgentDojo) kodla karar veriyor, yeni ve uzun ufuklu olan AgentLAB ise LLM hakemle. AgentDojo makalesinin kendi gerekçesi: "Eğer saldırı çok başarılıysa, değerlendirme modelini de ele geçirme ihtimali var." Yani saldırı kendi ölçümünü bozabilir. Bu cümle tezin için önemli: AgentLAB'in hakemi tam da bu riske açık. CAR-bench ikisini karıştırıyor: 12 kural kodla, 7 kural LLM hakemle.
