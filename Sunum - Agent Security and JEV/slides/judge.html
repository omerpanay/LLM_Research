The second problem is the judge.

Most tests use an LLM to decide if an attack worked, and this judge can make mistakes.

AgentLAB also uses an LLM (GPT-5.1) as its judge, and it does not check this judge against human labels.

That is why I am thinking of adding human labeled data so we can trust it more 

Hakem (judge) = saldırının başarılı olup olmadığına karar veren model. Hakem yanılırsa ASR sayısı da yanlış çıkar. Soru gelirse destek olarak: A Coin Flip for Safety makalesi 6.642 insan etiketiyle karşılaştırınca LLM hakemlerin saldırı testlerinde neredeyse tahmin etmek kadar kötü olduğunu buldu.
