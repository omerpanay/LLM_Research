1 · THE PROBLEM AND THE ATTACKS

All the papers I read point to one main problem.

An AI agent reads my instructions and the data it finds in the same way, as one long text. It cannot clearly tell which part is an order and which part is just information. So if someone hides an order inside a restaurant review or an email, the agent may follow it.

Chatbot

When a chatbot is tricked, it gives a bad answer.

Agent

When an agent is tricked, it does something: it sends an email, changes the route, or shares the location.

Ana fikir: ajan talimatı ve veriyi aynı metin gibi okuyor, ikisini ayıramıyor. Mektup örneği verebilirsin: asistana gelen mektupları oku dediğinde, mektuplardan birinde "parayı şu hesaba gönder" yazıyorsa, insan bunun emir olmadığını bilir ama yapay zekâ bilemez. Sağdaki kart en önemli farkı söylüyor: chatbot kötü cevap verir, ajan kötü bir iş yapar.
