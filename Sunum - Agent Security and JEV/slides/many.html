LONG-HORIZON ATTACKS

The problem is bigger when the attack is split over many messages.

Each message looks normal, so a filter that checks one message at a time does not see the attack.

Bu slaytta biraz dur. Uzun ufuklu (long-horizon) saldırının tanımı bu: saldırı birçok mesaja bölünüyor, tek tek bakınca hiçbiri kötü görünmüyor. Bu yüzden her mesajı ayrı kontrol eden filtreler saldırıyı kaçırıyor.
