3 · DEFENCES

Two more results surprised me.

First

Defences made for one message do not work well against many-step attacks. In AgentLAB, Llama Guard helps very little, because no single message looks bad.
In Zhaokun's Thesıs, I found that Llama Guard was  decreasing defence ability which is strange.

Second

Detectors do not work the same way on different tests. PIGuard finds 95.1% of attacks on one test (BIPIA) but only 2.1% on another (AgentDojo).

A detector seems to work only on text that looks like its training data, When you test it with other data like AgentDojo it makes a really bad score so I need to test it on my own car data.

Llama Guard her mesaja tek tek bakıyor; uzun ufuklu saldırıda hiçbir mesaj tek başına kötü olmadığı için yakalayamıyor. PIGuard örneği: aynı yanlış alarm oranında (yüzde 1) bir testte saldırıların yüzde 95,1'ini, diğerinde yüzde 2,1'ini buluyor. Sonuç: detektörü kendi araç verimizde test etmeden güvenemeyiz.
