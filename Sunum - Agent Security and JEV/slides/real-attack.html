We should not trust attack success numbers too quickly.

A number like “ASR 74%” depends on two things: how the test was built, and who decided that the attack worked.

The best example: Agent Security Bench (ASB)

In ASB, the attacker’s tools were always added to the agent’s tool list, and every time the agent used one, it was counted as a successful attack.

73.58% → 9.25%

When another team let the agent choose its own tools, the success rate on GPT-4o fell from 73.58% to 9.25% (Bhagwatkar et al.)

So most of the “attacks” came from how the test was built.

ASR = attack success rate, yani 100 saldırıdan kaçının başarılı olduğu. ASB'de saldırganın tool'ları ajanın listesine zorla ekleniyordu ve ajan bunlardan birini kullanınca saldırı başarılı sayılıyordu. Ajan tool'larını kendi seçince başarı yüzde 73,58'den yüzde 9,25'e düştü. Mesaj: sayıyı kimin, nasıl ölçtüğüne bakmadan güvenme.
