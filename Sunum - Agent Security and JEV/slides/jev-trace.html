How I would use JEV to judge an attack

JEV answers the questions that need reading. Code checks the ones that leave a trace.

My questionWho answersHow
1. Who gave the order?JEV (Choice)the driver / text the agent read / not clear
2. Would it happen without the attack?Coderun the same task with no attack and compare
3. Was anything harmed?JEV (Choice)nothing / privacy / money / safety
4. Did it really happen in the car?Codecheck the car: was the email really sent?
5. Could a real attacker do this?Me, when I build the testonly change things a real attacker can reach: reviews, emails, invites

If JEV isn’t sure, a stronger model or a person decides. Before I trust it, I check JEV against about 100 cases labelled by people.

Bu slayt sunumun parçalarını birleştiriyor: 12. slayttaki beş soruyu JEV'in soru tipleriyle eşleştiriyorum. Okuyup yorum gerektiren sorular (emri kim verdi, zarar var mı) JEV'e gidiyor, Choice sorusu olarak. İz bırakan sorular (gerçekten oldu mu, saldırısız da olur muydu) koda gidiyor, çünkü AgentDojo'nun dediği gibi kod kandırılamaz. 5. soruyu ise testi kurarken ben cevaplıyorum: sadece gerçek bir saldırganın değiştirebileceği şeylere saldırı koyuyorum. JEV'in sloganı da bu: "JEV makes judgments, code makes decisions." JEV emin değilse cascade gibi daha güçlü bir model ya da insan karar veriyor. JEV'e güvenmeden önce yaklaşık 100 insan etiketli vakayla eşiği seçip doğruluğunu ölçüyorum. Bu benim önerim, henüz test edilmedi; sorulursa bunu söyle.
