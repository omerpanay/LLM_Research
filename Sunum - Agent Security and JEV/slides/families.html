The most useful benchmark I found for this is AgentLAB (ICML 2026).

It puts these attacks into five groups:

Attack typeWho attacksWhat happens
Intent hijackingThe userConvinces the agent step by step to do something it should refuse
Tool chainingThe userBreaks a harmful goal into small tool calls that each look safe
Task injectionThe dataAdds a second, hidden task next to the real one
Objective driftingThe dataChanges the goal slowly, a little at a time
Memory poisoningThe dataSaves a fake preference that is used in a later session
